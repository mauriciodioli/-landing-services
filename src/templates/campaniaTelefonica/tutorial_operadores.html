1. Entrar al sistema

Abre DPIA CRM. Si ves contactos y tu usuario arriba, puedes seguir. Si no, primero debes validarte.

Boton Importar hoja
  1. Haz clic en Importar hoja.
  2. Escribe tu correo electronico.
  3. Escribe tu password.
  4. Haz clic en Validar acceso.

2. Confirmar que ya entraste

Cuando el acceso es correcto, el sistema muestra tu correo y tu ID en la caja Usuario activo.

Revisa Usuario activo
  • Si no aparece tu usuario, no importes nada todavia.
  • Si el sistema restaura tu sesion automaticamente, no necesitas volver a poner password.

3. Cargar una sheet

Dentro del modal Importar hoja completa los datos de la hoja que vas a trabajar.

El Sheet ID es el texto largo que aparece en la URL entre /d/ y /edit.

El Nombre visible puede ser el nombre con el que quieres reconocer esa hoja dentro del sistema. Normalmente puedes usar el nombre general del archivo, por ejemplo PSICOLOGOS (3616).

La Hoja / Tab es el nombre de la pestaña interna dentro del Google Sheet. En este ejemplo, la pestaña es Mauricio.

Es el nombre interno para trabajar esa carga dentro del sistema.

Puedes limitar la cantidad para trabajar por bloques.

4. Revisar antes de importar

Si quieres comprobar que la hoja fue reconocida correctamente, usa Analizar headers.

Botones Analizar headers Importar sheet
  • Esto sirve para revisar columnas como telefono, empresa, ciudad y email.
  • Si todo se ve bien, usa Importar sheet.

5. Trabajar los contactos

Cuando termina la importacion, aparecen las tarjetas de los contactos.

Buscar lead Estado Anterior Siguiente
  • Usa Buscar lead para encontrar empresas o telefonos.
  • Usa el filtro Estado para ordenar tu trabajo.
  • Usa Anterior y Siguiente para pasar de pagina.

6. Llamar o contactar

En cada tarjeta, el boton Llamar abre un menu con acciones disponibles.

VoIP WhatsApp Enviar email
  • VoIP para llamar con el softphone.
  • WhatsApp para abrir el chat.
  • Enviar email para compartir o abrir el correo.

7. Cambiar estado y guardar notas

Despues de cada gestion, actualiza el estado del contacto y deja una nota breve.

  • Ejemplos: LLAMADO, PENDIENTE, EXITOSO, NO_RESPONDE.
  • La nota ayuda a que el siguiente operador entienda que paso.

8. Usar historial de sheets

Si ya cargaste una sheet antes, no hace falta escribir todo otra vez.

Boton Historial sheets
  1. Abre Importar hoja.
  2. Haz clic en Historial sheets.
  3. Usa Usar esta sheet para rellenar el formulario automaticamente.

9. Eliminar una sheet importada

Si una campaña ya no sirve, puedes borrarla desde el historial.

Boton Eliminar
  1. Abre Historial sheets.
  2. Busca la campaña correcta.
  3. Haz clic en Eliminar.
  4. Confirma la accion.

Cuando el sistema esta borrando, el boton muestra Eliminando... con una ruedita.

Consejo importante

Antes de importar o borrar una campaña, revisa siempre el cuadro Usuario activo. Cada operador solo debe trabajar sus propias sheets y sus propias campañas.

Errores comunes

  • Importar sin validar acceso.
  • Escribir mal la pestaña o tab de la sheet.
  • Borrar una campaña sin revisar el nombre antes.

Regla simple de trabajo

Primero entra, luego valida, despues importa, luego trabaja los contactos y al final elimina solo lo que ya no necesitas.

Como llenar el Nombre visible

El Nombre visible es el nombre con el que verás esta sheet dentro de DPIA CRM.

Con tu ejemplo, el nombre recomendado es:

PSICOLOGOS (3616)

Usa el nombre general del archivo o un nombre que el operador reconozca rápido.

Como llenar la Hoja / Tab

La Hoja / Tab es la pestaña interna dentro del archivo de Google Sheets.

En este ejemplo, la pestaña que debes escribir es:

Mauricio

Debes escribir exactamente el nombre de la pestaña, respetando espacios y letras visibles.

Como llenar el Nombre de campana

El Nombre de campana es el nombre interno que verás en DPIA CRM para trabajar esta carga.

Un ejemplo claro con tus datos seria:

PSICOLOGOS (3616) - Mauricio

Usa un nombre corto, claro y facil de reconocer por el operador.
