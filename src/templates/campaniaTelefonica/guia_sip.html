Guia operativa

Configuracion SIP simple con {{ sip_softphone }} y {{ sip_provider }}

DPIA no cursa el audio ni almacena credenciales SIP. Solo inicia el enlace sip: y registra la gestion comercial.

Paso 1. Crear cuenta {{ sip_provider }}

  1. Registrar una cuenta en el portal de {{ sip_provider }}.
  2. Validar el email corporativo del vendedor.
  3. Cargar saldo para llamadas internacionales a Espana.
  4. Entrar al panel SIP y habilitar una extension o credencial SIP.

Paso 2. Crear extension SIP

Recoger y guardar de forma segura estos tres datos del proveedor:

  • SIP user, por ejemplo {{ sip_user }}
  • SIP password, solo en gestor seguro o configuracion local del vendedor
  • SIP server, por ejemplo {{ sip_server }}

Paso 3. Instalar Zoiper

  1. Windows: descargar e instalar Zoiper Desktop.
  2. Android: instalar Zoiper desde la tienda oficial.
  3. Aceptar permisos de microfono y notificaciones.

Paso 4. Configurar Zoiper

  1. Abrir Zoiper y crear una cuenta SIP.
  2. Ingresar usuario, password y host SIP.
  3. Verificar que la cuenta quede registrada y en linea.
  4. Configurar codec y dispositivo de audio segun el puesto de trabajo.

Paso 5. Probar llamada

  1. Realizar una llamada de prueba a un numero de Espana.
  2. Verificar audio de ida y vuelta.
  3. Confirmar latencia, calidad y facturacion esperada.

Paso 6. Integrar con DPIA

  1. Abrir la vista de campanas en DPIA.
  2. Hacer click en el boton Llamar.
  3. Comprobar que {{ sip_softphone }} capture el enlace sip:+34934885936.
  4. Finalizar la llamada y actualizar estado, nota e historial del lead.

Estado de activacion

Si {{ sip_provider }} todavia muestra la cuenta en revision o KYC pendiente, la conexion tecnica puede quedar preparada en DPIA, pero las llamadas reales no funcionaran hasta que el proveedor apruebe la cuenta.

Seguridad

  • No exponer passwords SIP en HTML, JS ni respuestas JSON.
  • No almacenar credenciales del softphone en la base de datos de DPIA.
  • Asignar permisos por usuario antes de permitir importacion o actualizacion de estados.
  • Usar un gestor seguro o el propio softphone para almacenar las credenciales localmente.
